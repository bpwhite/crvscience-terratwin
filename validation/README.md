# Validation Telemetry (`crvscience-terratwin` v2.5.0)

Deterministic headless empirical validation artifacts generated by running `cargo test --test headless_validation` directly against the compiled Rust physics engine (`terratwin_climate_hub`), schema catalog (`HubSchema`), and embedded SQLite layer store (`ClimateDatabase`).

## Test Protocols
1. **T1 (`t1_coupled_ssp_radiative_forcing_and_temp_trajectories`)**: Steps the coupled radiative-convective, 2-layer QGPV, and semi-Lagrangian advection engine from 1950 to 2100 across `SSP1-1.9`, `SSP2-4.5`, `SSP3-7.0`, and `SSP5-8.5` (annualized across spring/autumn phases `DOY 105` & `288`), writing trajectories to `ssp_projections_1950_2100.csv`.
2. **T2 (`t2_multilayer_cryosphere_ocean_slr_and_biome_aridity`)**: Evaluates 2100 multi-layer telemetry on a `144x72` spherical grid across February (`DOY 45`) and August (`DOY 225`), auditing Semtner sea-ice area/extent/thickness, thermosteric SWOT sea-level rise, 0–2000 m ocean heat content (EOS-80), and land biome fire-weather aridity stress.
3. **T3 (`t3_arctic_amplification_polar_to_tropics_ratio`)**: Verifies high-latitude Arctic amplification (`66.5°N–90°N` vs. `23.5°S–23.5°N`) across `SSP2-4.5`, `SSP3-7.0`, and `SSP5-8.5`.

## Output Files
- `ssp_projections_1950_2100.csv` — 1950–2100 coupled CO₂, radiative forcing, global/SST anomaly, and Arctic/Tropics warming timeseries.
- `terratwin_validation_summary.json` — Consolidated telemetry metrics for T1, T2, and T3 (also mirrored to `app-preprints/releases/terratwin-coupled-climate-ssp-validation-telemetry.json` in the parent monorepo).

## Reproducibility
```bash
cargo test --test headless_validation
```
